# P2 Mission — 2026-07-29

## Gate: state separation (P2.1)

Goal in one line: runtime state must live under one configurable root and must not depend on where the code is checked out, because the repository is going to move.

## Inventory findings

- ~25 distinct runtime-state stores exist across the codebase.
- 21 of those stores carry their own per-store environment variable.
- `ATLAS_STATE_ROOT` did not exist before this wave.
- Six stores resolve relative to the code checkout and would break on the move: exec-graph, evidence, goal-budgets, swarm-run bundles, operator-state, operator-runs.
- Of those six, operator-state and operator-runs carry no environment override at all today.
- Roughly half of the remaining stores already default under the home directory and survive a move without change.
- `src/atlas/mastra-agent.ts` reads `MEMORY_ROOT` inline instead of going through the shared helper in `src/atlas/path-util.ts` — a second implementation of one variable.
- `git ls-files state/` returns exactly three tracked files, all under `state/exec-graph/`.

## Wave A scope and result

Scope: the resolver module only (`src/atlas/state-root.ts`), no call-site migration — therefore no behaviour change in this wave.

Precedence: legacy per-store variable first (so existing deployments never break), then the single `ATLAS_STATE_ROOT`, with no cwd fallback.

Acceptance met:
- `tsc` clean.
- `npx vitest run src/__tests__/state-root.test.ts` — 18 passed, 0 failed.

## Remaining waves (named, not started)

- Migrate the six checkout-relative stores (exec-graph, evidence, goal-budgets, swarm-run bundles, operator-state, operator-runs) onto the resolver.
- Give operator-state and operator-runs an environment override where they currently have none.
- Fold the duplicate `MEMORY_ROOT` reader in `src/atlas/mastra-agent.ts` into the shared helper in `src/atlas/path-util.ts`.
- Decide git-tracking for the three `state/exec-graph` files — CEO-gated, those files are on the frozen do-not-touch list.
