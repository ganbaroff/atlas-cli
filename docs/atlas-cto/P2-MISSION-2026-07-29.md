# P2 Mission — 2026-07-29

## Gate: state separation (P2.1)

Runtime state must live under one configurable root and must not depend on the
code checkout location.

## Verified inventory boundary

- `ATLAS_STATE_ROOT` did not exist before Wave A.
- Path resolution is scattered across runtime modules.
- The initial migration registry contains eight known candidates:
  exec-graph, evidence, goal-budgets, swarm-runs, operator-state,
  operator-runs, intake-drafts, and task-results.
- This registry is not a claim of complete runtime-store inventory.
- The first inventory omitted checkout-relative `state/intake-drafts` and the
  legacy hardcoded `C:/Projects/ATLAS/data/task-results` writer.
- `git ls-files state/` returns three entries under `state/exec-graph`, but only
  `graph.json` and `ledger.jsonl` are generated runtime state. `.gitkeep` is
  repository metadata.
- Home-directory defaults survive a local checkout move but do not by
  themselves prove Railway-volume durability.
- `MEMORY_ROOT` is a separate memory-domain concern and is not part of this
  task/runtime-state registry.

Rejected earlier totals such as `~25 stores / 21 overrides / six
checkout-bound stores` are not used as architecture facts because the source
rows mixed state, configuration, aliases, and test-only paths.

## Wave A scope and result

Wave A adds the resolver and tests only. No call site is migrated, so runtime
behavior remains unchanged.

Precedence:

1. a non-empty stable absolute legacy per-store override;
2. `<ATLAS_STATE_ROOT>/<store>`;
3. default root `<homedir>/.atlas/state`.

Relative or Windows drive-relative override values fail closed. The resolver
never converts a relative value through process CWD.

Verification:

- `npx vitest run src/__tests__/state-root.test.ts`
- `npx tsc --noEmit`
- explicit tests cover relative root rejection, relative legacy override
  rejection, native absolute paths, and CWD invariance.

## Remaining waves

- migrate each verified call site onto the resolver in bounded slices;
- add stable per-store overrides only where backward compatibility requires
  them;
- copy and replay exec-graph state under the accepted root;
- prove cold read, event counts, zero malformed records, and snapshot parity;
- after that proof and matching ignore rules, untrack only generated
  `graph.json` and `ledger.jsonl` under Yusif's existing approval;
- retain `.gitkeep` unless the legacy directory is deliberately removed.

No call-site migration, state copy, untrack, ignore edit, push, merge,
scheduler change, Railway change, or physical move is part of Wave A.
